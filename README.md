# SimpleWindowsCare

A simple, free, no-ads Windows maintenance tool: live CPU / RAM / NVIDIA GPU monitor,
temp-file cleaner with preview, startup manager and uninstaller. Built as a lightweight
alternative to bloated "system optimizer" suites.

## Development

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
python -m simplewindowscare
```
